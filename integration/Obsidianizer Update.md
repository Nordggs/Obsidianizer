# Obsidianizer — Интеграция с Obsidian

## Что делает интеграция

При нажатии горячей клавиши (например, Alt+3) в Obsidian запускается обновление текущей карточки:
- Obsidianizer сканирует папку и обновляет Markdown-файл
- В карточке обновляются секции Gallery и Images
- Результат показывается уведомлением в Obsidian

## Способ А: Автоматическая установка

1. Откройте Obsidianizer → вкладка **Integration** (или кнопка «Obsidian Integration» в главном окне)
2. Укажите папку вашего Obsidian vault (в ней должна быть папка `.obsidian`)
3. Нажмите **Установить / Починить интеграцию**
4. Назначьте горячую клавишу: Obsidian → Настройки → Горячие клавиши → найдите команду Templater «Obsidianizer Update» → назначьте клавишу (например, Alt+3)

## Способ Б: Ручная установка

Если вы не хотите давать приложению доступ к папке vault, установите интеграцию вручную:

### Шаг 1. Установите Templater

1. В Obsidian откройте Настройки → Плагины сообщества
2. Найдите и установите **Templater**
3. Включите плагин

### Шаг 2. Скопируйте шаблон

1. Скопируйте файл `Obsidianizer Update Templater.md` из этой папки
2. Вставьте его в папку шаблонов Templater (по умолчанию `templates/` в корне vault)
3. Откройте скопированный файл и замените `{{CLI_PATH}}` на реальный путь к Obsidianizer:
   - Если используете сборку: путь к `Obsidianizer.exe` (например, `C:\Obsidianizer\Obsidianizer.exe`)
   - Если из исходников: путь к `obsidianizer-cli.bat` (например, `D:\Path\To\Obsidianizer\obsidianizer-cli.bat`)

### Шаг 3. Назначьте горячую клавишу

1. Obsidian → Настройки → Горячие клавиши
2. Найдите команду Templater «Obsidianizer Update»
3. Назначьте клавишу (например, Alt+3)

## Альтернатива: Shell Commands плагин

Для продвинутых пользователей доступен способ через плагин **Shell Commands**:

1. Установите плагин Shell Commands в Obsidian
2. Импортируйте команду из файла `shell-commands.json` (или создайте вручную)
3. Назначьте горячую клавишу

Команда вызывает CLI напрямую, без Templater.

## Проверка

После установки откройте любую карточку в Obsidian и нажмите назначенную клавишу. Должно появиться уведомление «Obsidianizer: обновлено · Gallery ✓ · Images ✓».
