# Obsidianizer

## [0.3.0] — Не выпущен

### Добавлено
- Десктопный GUI (`obsidianizer ui`, pywebview): выбор источника/результата,
  переключатель Ollama + модель, опции dry-run/prune, прогресс-бар, текущий
  файл, цветной журнал, итог, кнопка «Открыть результат». Чистый фронтенд
  поверх того же ядра.
- Честная остановка: `pipeline.run` получает `cancel_check` (опрос только
  между файлами; текущий файл — включая долгий вызов Ollama — доводится до
  конца).
- Гарантированный одиночный `FINISHED` на любом пути (обычное завершение,
  ошибка файла, отмена, фатальная ошибка запуска). `Report.cancelled` — только
  при пользовательской отмене; `Report.critical_error` фиксирует фатальные
  ошибки.
- Корневой лаунчер `Obsidianizer.py` / `Obsidianizer.bat`: двойной клик
  запускает GUI прямо из корня репозитория — установка пакета не нужна;
  `Obsidianizer.py --check` выводит диагностику без открытия окна.

## [0.2.0] — Не выпущен

### Добавлено
- Двуязычная документация (RU + EN): `README.ru.md`, `AGENTS.ru.md`,
  `CHANGELOG.ru.md`, `docs/*.ru.md`; политика двуязычности в `AGENTS.md`.
- Контракт событий (`events.py`): `SCAN_STARTED`, `FILE_STARTED`,
  `LLM_STARTED`, `FILE_DONE`, `FILE_SKIPPED`, `FILE_ERROR`, `FINISHED`.
  `pipeline.run` принимает необязательный колбэк `on_event`; ядро остаётся
  независимым от способа отображения.
- Плейсхолдер будущего GUI (`ui.py`) и каталог `assets/`.
- Архитектурная документация: раздел «Слой UI» с протоколом событий.

## [0.1.0] — Не выпущен

### Добавлено
- Каркас репозитория: src layout, pyproject, тесты, документация, контракт AGENTS.
- Ядро конвейера: scan → extract → enrich → emit.
- Безопасность: guard (запрет пересечения source/target), манифест владения,
  атомарная запись.
- Процессор Markdown для сырых экспортов чатов ИИ (извлечение метаданных +
  резюме/теги через Ollama, корректная деградация при недоступной LLM).
- Инкрементная обработка через `source_hash` в frontmatter результата.
- Генерация `_index.md` для навигации по vault.
