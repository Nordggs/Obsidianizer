# Разработка

> **Русский** | [English](development.md)

## Окружение

Требования: Python 3.10+ (разработка на 3.14), git.

```bash
git clone <repo> && cd Obsidianizer
python -m venv .venv
.venv\Scripts\activate          # Windows
# или: source .venv/bin/activate  # POSIX

pip install -e .[dev]
```

## Запуск тестов

```bash
pytest
```

Набор построен вокруг «безопасность прежде всего»:

| Файл теста             | От чего защищает                                  |
|------------------------|---------------------------------------------------|
| `test_guard.py`        | отказы при пересечении путей (случаи уничтожения) |
| `test_manifest.py`     | prune только своих файлов; атомарная запись манифеста |
| `test_md_processor.py` | разбор метаданных; сохранение тела                |
| `test_registry.py`     | диспетчеризация расширений; неизвестные расширения |
| `test_config.py`       | приоритет CLI > config > дефолты; roundtrip save/load + merge |
| `test_ui.py`           | GUI-мост: персистентность настроек, выбор папок по полям |
| `test_pipeline.py`     | инкрементальность; деградация LLM                 |

## Фикстуры

`tests/fixtures/` зеркалирует реалистичные раскладки сырых данных:

```
tests/fixtures/md/       образец сырого Markdown (стиль заголовков AI-чата)
tests/fixtures/media/    привязанные бинарные ассеты
```

## Соглашения

- `src` layout: пакет должен потребляться как установленный пакет, никогда —
  как ad-hoc импорт локальной папки.
- Обработка аргументов CLI живёт только в `cli.py`.
- Пути — `pathlib.Path`; сравнения идут через `Path.resolve()` и
  нормализуются по регистру.
- Вся запись атомарна (`os.replace`).
- Нет облака/API-ключей: LLM-клиент только локальный Ollama.
- Держи ядро конвейера свободным от специфики типов файлов.
