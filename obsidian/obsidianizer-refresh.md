# Obsidianizer: обновить карточку текущей папки из Obsidian

Обновление **только той** карточки, в которой вы находитесь — без запуска GUI.

> Ключевое: обновление запускает **командную обёртку** `obsidianizer-cli.bat`
> (лежит рядом с `Obsidianizer.bat`). Полный путь к ней указан ниже —
> установка пакета в PATH не требуется. Если репозиторий у вас в другом
> месте — замените `D:\Main\OpenCode\Obsidianizer` на свой путь.

---

## Вариант 1 (основной) — плагин Shell commands

Плагин сам подставляет папку текущей заметки через `{{folder_path}}`.

1. Установите плагин **Shell commands**.
2. Настройки → Shell commands → Новая команда:
   - **Название**: `Obsidianizer: обновить карточку`
   - **Команда**:
     ```
     "D:\Main\OpenCode\Obsidianizer\obsidianizer-cli.bat" folders --path "{{folder_path}}" --no-recursive --adopt --vault-root "{{vault_path}}" --rel "{{relative}}"
     ```
     *(Obsidian сам подставляет корень vault через `{{vault_path}}` и путь
     папки относительно vault через `{{relative}}` — галерея получает
     правильный путь, а ссылка «⬆ Up» остаётся корректной. Флаг `--adopt`:
     если в папке лежит чужая заметка без маркера obsidianizer — она будет
     переименована в `<имя>_заметки.md` (содержимое 1:1) и создастся новая
     карточка)*
3. Назначьте горячую клавишу: Настройки → Горячие клавиши → найдите команду
   → задайте **Alt+F3**.

---

## Вариант 2 (без Shell commands) — Templater

Если не хочется ставить Shell commands, но уже есть Templater.

1. Скопируйте файл `obsidian/templater/Obsidianizer Update.md` в папку
   шаблонов Templater (Настройки → Templater → Папка шаблонов).
2. Внутри шаблона прописан полный путь к `obsidianizer-cli.bat` — при
   необходимости замените его на свой. Корень vault и путь папки
   подставляются автоматически (`--vault-root` + `--rel`), флаг `--adopt`
   переводит чужую заметку (если она есть) в `<имя>_заметки.md`.
3. Назначьте команду шаблона горячую клавишу (Alt+3) либо вызывайте через
   палитру Templater → выберите шаблон `Obsidianizer Update`.

При успехе приходит Notice с самодиагностикой: `Obsidianizer: обновлено ·
Gallery ✓/✗ · Images ✓/✗` — сразу видно, что галерея и архив изображений
сгенерированы.

> Если путь к программе у вас другой — замените в шаблоне/команде
> `D:\Main\OpenCode\Obsidianizer` на свой.
>
> **Проще**: в самом приложении есть кнопка **🔗 Obsidian Integration** —
> она скопирует шаблон в папку Templater и подставит корректный путь к CLI
> автоматически. Хоткей всё равно назначается вручную (шаг ниже).

---

## Проверьте хоткей

Obsidianizer **не назначает** горячие клавиши Obsidian автоматически и не
редактирует `hotkeys.json` вашего хранилища — клавишу проверяет и назначает
пользователь:

1. Откройте Obsidian → Настройки → Горячие клавиши.
2. Найдите команду Templater, связанную с шаблоном «Obsidianizer Update».
3. Проверьте назначенную клавишу (например, `Alt+3`) или назначьте свою.
4. Откройте карточку проекта и выполните команду — карточка обновится.

## Что происходит внутри

```
Открытая карточка <Проект>.md
        │  определяется её папка
        ▼
obsidianizer-cli.bat folders --path "<эта папка>" --no-recursive --adopt
        │
        ├── читает <Проект>_заметки.md (поля проекта + ваши заметки)
        ├── сравнивает с манифестом карточки (что изменилось)
        └── пересобирает ТОЛЬКО эту карточку:
            Folders / Files / About / Gallery / Images / AI Review / Notes / footer
```

- Исходные файлы **никогда не изменяются**.
- `*_заметки.md` — ваша территория, не перезаписывается.
- `--no-recursive` обновляет только эту карточку, но агрегаты подпапок
  (Files/Size/Updated в таблице Folders) считает по полному поддереву —
  карточка идентична результату рекурсивного запуска GUI.
- Правки полей проекта в `<Проект>_заметки.md` подхватываются при
  следующем обновлении (карточка честно помечается устаревшей, без фантомных
  «добавлен/удалён» для неизменённых файлов).
