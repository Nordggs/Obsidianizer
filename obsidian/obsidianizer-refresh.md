# Obsidianizer: обновить карточку текущей папки из Obsidian

Обновление **только той** карточки, в которой вы находитесь — без запуска GUI.

> Ключевое: обновление запускает **командную обёртку** `obsidianizer-cli.bat`
> (лежит рядом с `Obsidianizer.bat`). Полный путь к ней указан ниже —
> установка пакета в PATH не требуется.

---

## Вариант 1 (основной) — плагин Shell commands

Плагин сам подставляет папку текущей заметки через `{{folder_path}}`.

1. Установите плагин **Shell commands**.
2. Настройки → Shell commands → Новая команда:
   - **Название**: `Obsidianizer: обновить карточку`
   - **Команда**:
     ```
     "D:\Main\OpenCode\Obsidianizer\obsidianizer-cli.bat" folders --path "{{folder_path}}" --no-recursive --adopt --vault-root "{{vault_path}}"
     ```
     *(Obsidian сам подставляет корень vault через `{{vault_path}}` — галерея
     получает правильный путь без ручных настроек. Флаг `--adopt`: если в
     папке лежит старая заметка без маркера obsidianizer — она будет
     переименована в `<имя>_заметки.md` (содержимое 1:1) и создастся новая
     карточка)*
3. Назначьте горячую клавишу: Настройки → Горячие клавиши → найдите команду
   → задайте **Alt+F3**.

---

## Вариант 2 (без Shell commands) — Templater

Если не хочется ставить Shell commands, но уже есть Templater.

1. Скопируйте файл `obsidian/templater/Obsidianizer Update.md` в папку шаблонов
   Templater.
2. Внутри шаблона прописан полный путь к `obsidianizer-cli.bat`; корень vault
   подставляется автоматически (`--vault-root`), флаг `--adopt` переводит
   старую заметку (если она есть) в `<имя>_заметки.md`. Настраивать вручную
   ничего не нужно.
3. Откройте карточку проекта → вызовите Templater (Alt+3) → выберите
   шаблон `Obsidianizer Update` → карточка обновится.

> Если путь к программе у вас другой — замените в шаблоне/команде
> `D:\Main\OpenCode\Obsidianizer` на свой.

---

## Что происходит внутри

```
Открытая карточка <Проект>.md
        │  определяется её папка
        ▼
obsidianizer-cli.bat folders --path "<эта папка>" --no-recursive
        │
        ├── читает <Проект>_заметки.md (поля проекта + ваши заметки)
        ├── сравнивает с манифестом карточки (что изменилось)
        └── пересобирает ТОЛЬКО эту карточку:
            Code / README (📋 Карточка проекта) / Images / Notes / footer
```

- Исходные файлы **никогда не изменяются**.
- `*_заметки.md` — ваша территория, не перезаписывается.
